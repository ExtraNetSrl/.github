# Extra-Net S.r.l.

Software consultancy based in Turin, Italy. We design and build cloud-native systems on .NET, Azure and Kubernetes, with a growing focus on applied AI, and we teach what we build.

## Open source

- [ExtraNet.GlobalAzureKit](https://github.com/ExtraNetSrl/ExtraNet.GlobalAzureKit) — IoT workshop kit for Global Azure Torino 2026: ESP32-C3 telemetry to Azure IoT Hub, Terraform infrastructure, real-time dashboard

We contribute upstream to the tools we rely on: Semantic Kernel, Orleans, Rebus, MassTransit, Bitnami charts, Camunda.

## Training

Extra-Net delivers Cloud, Azure and AI courses at ITS Academies in Piedmont (ITS ICT Piemonte, ITS Agroalimentare), and hosts apprenticeships and school-to-work programs with ITTS Grassi, IIS Peano and the University of Turin.
